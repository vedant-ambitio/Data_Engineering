================================================================================
  D) SUMMARY — SOURCE COVERAGE MAP
================================================================================

  Total fields to fill (excluding system/auto fields): ~115

  SOURCE BREAKDOWN:
  -----------------

  [MD] Markdown Files — Primary source for:
    - Program identity (name, degree, major, level, specialization)
    - Tuition fees (per year, total, per credit)
    - Application fee and currency
    - Deadlines (intake, round, dates, tags)
    - Test scores (TOEFL, IELTS, GRE, GMAT minimums)
    - Official links and URLs (program page, admissions, application)
    - Duration and intake terms
    - Basic overview description
    - Scholarships and funding details
    - Contact info (email, phone)
    - Work experience requirements

  [BF] BigFuture (US colleges only, 530/763 UG universities matched):
    - University demographics (race/ethnicity breakdown -> StudentDiversity rows)
    - Acceptance rate (university + program level)
    - SAT/ACT score ranges (25th/75th percentile + sub-scores)
    - GPA distribution
    - Retention rate (sophomore return %)
    - Graduation rate
    - Enrollment numbers (undergrad, fulltime, parttime)
    - International student %
    - Average aid awarded
    - Housing cost, books, transportation, personal expenses
    - Average net price (overall + by income bracket)
    - Application fee amount
    - Fee waiver availability
    - University type (public/private)
    - Address (street, city, state, zip)
    - School setting, size, commuter/residential
    - Admission policy details (GPA/rank/course requirements)
    - Common App URL, application site URL
    - Early decision/action/regular decision dates
    - Notification date
    - CollegeBoard code (diCode), IPEDS ID
    - Social media links
    - Majors list with CIP codes
    - AP credit policies

  [GE] Gemini Structured Extraction — Primary source for:
    - Structured JSON fields (admission_requirements_data, eligibility_criteria_data,
      course_structure_data, faculty_data)
    - Entry requirements list (SOP, LOR, Resume, etc. with counts)
    - Eligibility criteria (degree type, GPA, work experience)
    - Pointers, why_study_points, reasons_to_consider
    - Career outcomes (description, job roles, recruiters) - can infer
    - Program insight, application requirements insight
    - Cost of living estimates (when not in markdown)
    - STEM designation
    - Department/school name (when not explicit)
    - Duration (when not explicit, can infer)
    - Delivery mode
    - Who is this program for description
    - FAQ generation
    - Application process steps

  [RANK] External Rankings Data:
    - QS World University Rankings (qsRank, qsRankYear)
    - THE World University Rankings (thRank, thRankYear)
    - US News & World Report (usnRank, usnRankYear)
    - Subject-specific program rank (programRank)

  [MANUAL] Admin / Manual Input:
    - University logos (logo, shortLogo)
    - Gallery images
    - Company logos (recruiters)
    - Test definitions (ProgramExamTest records)
    - Entry requirement definitions (EntryRequirements records)
    - Eligibility criteria definitions (EligbilityCriteria records)
    - View priority
    - Tags

  [CALC] Calculated Fields:
    - slug (from university name)
    - overallCostPerYear (tuition + living)
    - totalCostOfLivingPerYear
    - roi_score (from ROI model)
    - cost_of_living_index


================================================================================
  E) FIELD GAPS — WHAT WE CANNOT FILL FROM CURRENT SOURCES
================================================================================

  These fields have NO reliable automated source:

  1. University logos (logo, shortLogo)          — Need web scraping or manual upload
  2. Gallery images (galleryImages)               — Need campus photo sourcing
  3. Company logos (Company.logo)                  — Need logo API or manual upload
  4. Test logos (ProgramExamTest.logo)             — One-time manual upload
  5. programRank (subject-specific)               — Need subject ranking datasets
  6. greSchoolCode / gmatSchoolCode / toeflCode   — Need ETS/GMAC lookup tables
  7. view_priority                                — Manual curation
  8. qs_name                                      — QS dataset matching
  9. globalRank                                   — Composite calculation
  10. roi_score                                   — Needs salary + cost model

  BigFuture limitations:
  - US colleges only (non-US universities get no BF enrichment)
  - College-level data only (same data for all programs at same university)
  - No TOEFL/IELTS scores (only SAT/ACT)
  - No per-program acceptance rates (only university-wide)
  - No per-course tuition differences
