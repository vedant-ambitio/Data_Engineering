  2) SUMMER SCHOOL MARKET — WHAT EXISTS
================================================================================

  Summer schools (pre-college programs) are short university programs
  (2-12 weeks) during summer. Students attend lectures, do projects,
  live on campus, and sometimes earn college credits.

  IMPORTANT: Listings are PROGRAM-wise, not college-wise.
  One university can have multiple programs:
    Harvard alone → Pre-College, Secondary School, Pre-Med, STEM = 4+ programs
    Stanford     → Pre-Collegiate, Summer College, AI4ALL = 3+ programs

  THREE TIERS:

    Tier 1 — FREE, ultra-prestigious (<5% acceptance)
      RSI (MIT), MITES (MIT), PROMYS (Boston), ROSS (Ohio State),
      ISRO YUVIKA, Clark Scholars
      Count: ~15-20 programs

    Tier 2 — PAID, prestigious ($3,000-$10,000, 15-30% acceptance)
      Harvard Pre-College ($6,100), Yale YYGS ($7,000),
      Stanford Pre-Collegiate ($8,000+), Oxford ($5,000+),
      Columbia, NUS, UCL, JHU, UChicago
      Count: ~70-100 programs

    Tier 3 — INDIA programs (INR 10K-85K, moderate selection)
      Ashoka YSP (INR 49,500), Plaksha YTS, IISER Bhopal,
      IIT Jammu/Delhi summer camps, Maker's Asylum
      Count: ~30-50 programs

  REALISTIC SCOPE FOR CLASS 9-12 INDIAN STUDENTS:

    A 15-year-old in India will NOT fly abroad for a 2-week program
    (visa issues, $10K+ cost, parents won't allow). They will:
      - Attend India programs in-person (affordable, no visa)
      - Join international programs ONLINE (from home)

    So we list:
      1. India programs (in-person + online)  → ~50-60 universities
      2. International ONLINE/REMOTE only     → ~25-35 universities
      3. DROP all abroad in-person programs

================================================================================
  4) DATA SOURCES
================================================================================

  Per PDF spec: "Maintain a curated database. Do not scrape dynamically —
  these pages change layout frequently. Manual review is more reliable."

  This is the MOST MANUAL section of Activity Finder.

  NO SINGLE SOURCE EXISTS for summer schools (unlike Internshala for
  internships or unstop for competitions). Closest are:
    - SummerMatchPoint: 1,600+ programs but AI tool, not scrapeable DB
    - College Transitions: 200+ but US-only, JS-rendered
    - No platform covers both India + international

  KEY INSIGHT: Universities are fixed. Programs change.
  Harvard, MIT, IIT Delhi don't change — but their programs, dates,
  fees change yearly. So we hardcode universities, auto-discover programs.


  SCRAPING APPROACH (5 steps):
  ────────────────────────────

  Step 1: AUTO-DISCOVER PROGRAMS (replaces manual list building)

    Hardcode a list of 80-100 target universities:
      USA:   Harvard, MIT, Stanford, Yale, Columbia, JHU, Brown, etc.
      UK:    Oxford, Cambridge, UCL, Imperial, LSE, Edinburgh
      Asia:  NUS, HKU, NTU, Tokyo
      India: IITs, IISERs, Ashoka, Plaksha, ISRO, FLAME, Jindal

    For each university, ask Gemini (web-grounded):
      "What pre-college summer programs does [Harvard] offer for
       high school students in 2026? List program names and URLs."

    Gemini returns ~1-4 programs per university with official URLs.
    Result: ~150-200 programs auto-discovered.

    Why Gemini, not manual scraping:
      - Catches NEW programs (if Harvard launches a new one, Gemini knows)
      - Handles 80-100 universities in one batch (~5 min)
      - No need to manually read 7 curated articles


  Step 2: VALIDATE URLs

    For each discovered URL:
      a) HTTP HEAD check — is URL alive? (dead = discontinued)
      b) Fetch page content (HTTP first, Puppeteer for JS-heavy)
      c) Keyword check: does page mention "2026" or "summer"?
         (catches stale/old pages before sending to Gemini)


  Step 3: EXTRACT DATA (same pattern as olympiad scraper)

    For each program, scrape TWO pages:
      a) University summer landing page (e.g. summer.harvard.edu/)
         → has cost comparison tables, deadline summaries
      b) Specific program page (e.g. .../pre-college-program/)
         → has eligibility, curriculum, application details

    Send both to Gemini with 29-field schema → structured JSON output.


  Step 4: CROSS-VALIDATE (safety net)

    Compare extracted data against 2-3 curated articles:
      - College Transitions (200+ programs with costs/deadlines)
      - Lumiere Education (35 programs with details)
      - CollegeAccessProgram.in (16 India programs)

    If extracted cost/deadline differs by >20% from article → flag
    for manual review. Same pattern as UG course merge (BigFuture
    vs markdown cross-validation).


  Step 5: ANNUAL REFRESH (January each year)

    a) Re-run Step 1 → Gemini rediscovers programs
       (catches new programs, flags removed ones)
    b) Re-run Steps 2-4 → re-scrape, re-extract, re-validate
    c) DIFF against last year's data:
       New programs       → add (content team reviews)
       Removed programs   → flag for removal
       Changed fees/dates → auto-update
       Same data          → no action
    d) Content team reviews ONLY the diff (~20-30 changes)
       NOT all 150 programs — saves significant time

    Timeline:
      January:  Full refresh (Steps 1-5)
      March:    Final check before application season opens
      Rest of year: No updates needed


  ESTIMATED EFFORT:

    First run (one-time):
      Step 1 (university list):      ~2 hours (hardcode 80-100 universities)
      Step 1 (Gemini discovery):     ~10 min automated
      Steps 2-4 (scrape + extract):  ~1-2 hours automated
      Content team review:           ~3-4 hours
      Total:                         ~7-8 hours

    Annual refresh:
      Steps 1-4 automated:           ~1-2 hours
      Content team reviews diff:     ~2-3 hours
      Total:                         ~4-5 hours/year

  5) FIELD COVERAGE ESTIMATE

  We scrape directly from university official pages — not aggregator
  platforms. Universities WANT to show everything to attract applicants,
  so coverage is the highest of all Activity Finder sections.

  COVERAGE AT EACH STAGE:

    Stage                    Fields    Out of 29    Coverage
    ----------------------   --------  ----------   --------
    Landing page only        18-22     29           62-76%
    + Program detail page    23-26     29           79-90%
    + Gemini enrichment      25-28     29           86-97%

  WHY SO HIGH:

    University summer program pages are designed to convert applicants.
    They show cost breakdowns, eligibility criteria, deadlines, curriculum,
    application steps — all prominently. Unlike aggregator platforms
    (unstop, Internshala) that lose detail fields, the official page IS
    the source of truth.

  COMPARISON ACROSS ALL ACTIVITY FINDER SECTIONS:

    Section          Source type        Coverage (with Gemini)

    Olympiads        Mixed official     ~88%
    Competitions     Aggregators        ~75%
    Internships      Internshala        ~85%
